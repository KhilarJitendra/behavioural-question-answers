## (3) Challenging Recent Task ?

**Topic:** Address management in checkout (VCA project)

### Situation:
In the Van Cleef & Arpels e-commerce project, the checkout flow had issues with address handling.  
Different countries had different address formats, and this was causing validation errors and user drop-offs during checkout.

### Task:
My task was to fix and improve the address management part of the checkout, so that it worked correctly for multiple countries and was easy to maintain.

### Action:
I refactored the address form into a reusable React component and moved country-specific validation logic into a custom hook.  
I worked with the backend team to clearly understand required fields for each country.  
I also added proper error handling and updated E2E tests to cover different address scenarios.

### Result:
After this change, address-related checkout issues reduced significantly.  
The code became easier to maintain, and adding support for new countries became faster and safer.

### Tech:
From a production point of view in Next.js, I separated the address form UI into a reusable React component, moved country-specific validation into a custom hook using config-based rules,  
coordinated with backend teams to align on required fields, ensured final validation on the server, and added E2E tests to safely handle multiple country address scenarios.

## (4) Conflict Resolve

- When a conflict happens, I first try to clearly understand both sides by listening carefully to everyone involved.
- I focus on the problem, not on the person, and ask questions to understand the real concern—whether it is timelines, performance, or business impact.
- I then suggest a solution based on data, best practices, or trade-offs, and align it with product and technical goals.
- If needed, I involve the right stakeholders early to avoid delays.
- The goal is always to reach a decision that is best for the product and the team, while keeping communication respectful and transparent.

## (6) Tell me about a challenging task you worked on

A challenging task I worked on was improving address management in the checkout flow for the VCA project.

The main challenge was that address formats and validation rules varied across countries, which was causing validation errors and user drop-offs during checkout.

To solve this, I refactored the address form into a reusable React component and moved country-specific validation logic into a custom hook using configuration-based rules. I worked closely with backend teams to clearly align on required fields and ensured final validation was also handled on the server side.

I also added E2E test coverage to handle multiple country scenarios safely. This significantly reduced checkout errors and made the system easier to scale when adding new countries.

During the VCA checkout work, there was a situation where I disagreed with a stakeholder on implementing a quick UI-only fix for an address issue to meet a tight deadline.

I felt that a UI-only fix would solve the immediate problem but would introduce long-term technical debt and repeated issues for other countries.
